# Public demo (GitHub Pages)

Live at https://mladjabiznis1-source.github.io/sales-tracker/ (branch `gh-pages`).
The real app plus `adapter.js`, which replaces the Netlify server: places come live from OpenStreetMap, data is saved in the visitor's browser, no student logins.
Rebuild: `cd static-demo && python3 build.py`, then publish `dist/` to the `gh-pages` branch.
